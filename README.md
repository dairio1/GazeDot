# GazeDot

Círculo flotante sobre cualquier app, controlado con las teclas de un teclado externo.

## Obtener el APK
1. En este repositorio, abre la pestaña **Actions**.
2. Entra al último "Build APK" (con palomita verde).
3. Abajo, en **Artifacts**, descarga **GazeDot-APK** (es un .zip con app-debug.apk dentro).

## Usar
1. Instala el APK y ábrelo.
2. Toca "Abrir ajustes de accesibilidad" y activa GazeDot.
3. Conecta tu teclado y mueve el círculo (por defecto, con las flechas).
